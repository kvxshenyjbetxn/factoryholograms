# Factory Holograms

[Українською](README.uk.md)

Add holographic names and input/output item icons to machines and other blocks in **Minecraft 1.7.10**.

Labels are visible only to you. No server installation is needed. You choose the names and icons yourself; the mod does not read machine recipes or contents.

Tested on **GTNH 2.9.0 RC-2**. Works without GregTech or NEI.

## Install

1. Download **`factoryholograms-0.7.4.jar`** from the [latest release](https://github.com/kvxshenyjbetxn/factoryholograms/releases/latest).
2. Place it in your game's **`mods/`** folder. Remove the older Factory Holograms JAR if installed.
3. Start the game.

## Use

1. Look at a nearby block and press **Shift+H**.
2. Enter a name and drag item icons from your inventory or **NEI** into the input/output slots.
3. Adjust the position if needed and click **Apply**.

Real items stay in place. Each label holds up to **16 input icons and 16 output icons**. Right-click a slot to clear it.

- **Shift+H** on the original block — edit its label.
- **H** — show or hide all labels.
- **Delete** in the editor — remove the label, not the block.
- **Escape** — cancel unsaved edits; first clears any item copy on the cursor.

## Settings

Change colors, opacity, visibility distance and auto-rotation in **Mods → Factory Holograms → Config**. For manual rotation, turn off auto-rotation and use **Rotation / tilt** in the editor.

Change the H key in **Options → Controls → Factory Holograms**.
