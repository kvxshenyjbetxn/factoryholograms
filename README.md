# Factory Holograms

[Ukrainian](README.uk.md)

Holographic names and input/output item icons above machines and other blocks in **Minecraft 1.7.10**.

Labels are visible only to you, no server install needed. You pick the names and icons yourself. Tested on **GTNH 2.9.0 RC-2**; works without GregTech and NEI.

https://github.com/user-attachments/assets/96eca09f-0427-4458-8abf-a039270e8394

## Install

1. Download **`factoryholograms-0.7.9.jar`** from the [latest release](https://github.com/kvxshenyjbetxn/factoryholograms/releases/latest).
2. Put it in your game's **`mods/`** folder, replacing any older Factory Holograms JAR.

## Quick start

Look at a block, press **Shift+H**, enter a name, drag item icons into the input/output slots and click **Apply**. Real items stay in your inventory.

A label holds up to **8 recipes** with up to **16 inputs and 16 outputs** each. When one label's output matches another's input, a line links them automatically.

## Controls

**In the world**

| Key | Action |
|---|---|
| **Shift+H** on a block | Create or edit its label |
| **H** | Show / hide all labels |
| **Ctrl+H** | Link lines: looked-at label / all / off |
| **L** | Turn link lines on / off |
| Aim at an icon | Show its tooltip (hold **Shift** for full) |
| **R** / **U** while aiming at an icon | Open NEI recipes / uses |

**In the editor**

| Action | How |
|---|---|
| Set an icon | Drag or click an item from inventory or NEI |
| Fill in the name | Drop an icon on the name field |
| Clear a slot | Right-click it |
| Switch / add / remove recipes | Arrows and **+** / **-** above the slots |
| Remove the label | **Delete** button |
| Cancel changes | **Escape** |

**H** and **L** can be rebound in **Options → Controls → Factory Holograms**.

## Settings

Colors, opacity, view distance, auto-rotation, tooltips and link lines: **Mods → Factory Holograms → Config**. For manual rotation, turn off auto-rotation and use **Rotation / tilt** in the editor.
