# Factory Holograms

[English](README.md)

Особисті голографічні підписи для машин та інших блоків у **Minecraft 1.7.10 / Forge**, зокрема **GTNH**. Додавайте назву та іконки входів і виходів, щоб легше орієнтуватися у своїй фабриці.

**Лише для клієнта:** голограми бачите тільки ви, на сервер нічого встановлювати не потрібно. Це ручні підписи, а не автоматичний показ рецептів, ресурсів чи прогресу машин. Справжні предмети не переміщуються й не витрачаються.

## Встановлення

1. Завантажте **`factoryholograms-0.7.4.jar`** з [останнього релізу](https://github.com/kvxshenyjbetxn/factoryholograms/releases/latest).
2. Покладіть його в папку **`mods/` вашого інстансу Minecraft**, видаливши попередній JAR Factory Holograms.
3. Запустіть гру.

GregTech і NEI не обов’язкові. Файли з `dev` або `sources` у назві для встановлення не підходять.

## Як створити голограму

1. Наведіться на машину або інший блок поблизу й натисніть **Shift+H** (до 6 блоків, у межах звичайної дальності наведення).
2. Введіть назву. Перетягніть предмети з інвентарю або **NEI** у слоти входу й виходу або клікніть предмет, а потім слот. Копіюється лише іконка.
3. За потреби налаштуйте положення й натисніть **«Готово» / Apply**, щоб зберегти.

Можна додати **16 іконок входу та 16 іконок виходу**, по 4 у ряд. **ПКМ по слоту** прибирає іконку.

Для редагування знову наведіться на **початковий блок** і натисніть Shift+H. **«Стерти» / Delete** видаляє лише мітку, не блок. **Escape скасовує незбережені зміни**; якщо на курсорі є копія предмета, перше натискання прибирає тільки її.

## Керування та вигляд

| Дія | Клавіша або налаштування |
| --- | --- |
| Створити або редагувати мітку | **Shift+H** |
| Сховати / показати всі голограми | **H** |
| Приховати разом з інтерфейсом | **F1** |
| Перепризначити H (Shift використовує ту саму клавішу) | **Options → Controls → Factory Holograms** |
| Кольори, непрозорість, дальність, автоповорот | **Mods → Factory Holograms → Config** |

- Нова голограма з’являється біля бічної грані блока. Якщо навестися зверху чи знизу, бік вибирається в напрямку до вас.
- **− / + по X/Y/Z** рухають її на **0,25 блока**, із **Shift — на 1 блок**. **«Скинути позицію»** повертає початкове положення.
- **«Перегляд позиції»** ховає велике вікно редактора, щоб було видно результат. **«До редактора»** повертає його без втрати чернетки.
- За замовчуванням голограма повертається до гравця. Для ручних кутів вимкніть **«Автоповорот до гравця»** в конфігурації та відкрийте **«Поворот / нахил»** у редакторі.

Зміни положення й кутів видно відразу; **«Готово»** зберігає їх.

## Резервні копії та перенесення на інший ПК

Мітки зберігаються локально, окремо для кожного сервера, одиночного світу та виміру. Закрийте гру й скопіюйте папку **`factoryholograms/`** з ігрової папки вашого інстансу. У Prism/MultiMC це ігрова папка відповідної збірки, а не загальна `.minecraft`.

**`/fholograms path`** показує точний шлях до файла поточних міток. Після повторного збереження попередня версія залишається поруч як **`.bak`**. Зміна адреси сервера або папки одиночного світу може вибрати інше сховище міток.

## Проблеми та сумісність

- **Редактор не відкривається:** підійдіть ближче, наведіться на блок і перевірте конфлікти клавіші H.
- **Голограм не видно:** увімкніть їх клавішею H, вийдіть із режиму F1, перевірте дальність і непрозорість у конфігурації. Голограми не видно крізь непрозорі стіни.
- **Немає NEI:** перевірте, що NEI встановлено та його панель увімкнена. Без NEI можна використовувати свій інвентар.
- **Зміни зникли:** зберігайте кнопкою **«Готово» / Apply**; Escape скасовує чернетку.

Автор перевіряв мод на **GTNH 2.9.0 RC-2**. Окремі результати перевірки рендерингу з Angelica та NEI на багатокористувацьких серверах поки не задокументовані. Перевірте правила вашого сервера щодо клієнтських модів.

Про проблеми повідомляйте в [Issues](https://github.com/kvxshenyjbetxn/factoryholograms/issues), додаючи версії збірки й мода та кроки відтворення.
