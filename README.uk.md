# Factory Holograms

[English](README.md)

Голографічні назви та іконки входів і виходів для машин та інших блоків у **Minecraft 1.7.10**.

Мітки бачите тільки ви. На сервер нічого встановлювати не потрібно. Назви й іконки ви вибираєте самі — мод не зчитує рецепти чи вміст машин.

Перевірено на **GTNH 2.9.0 RC-2**. Працює без GregTech і NEI.

## Встановлення

1. Завантажте **`factoryholograms-0.7.4.jar`** з [останнього релізу](https://github.com/kvxshenyjbetxn/factoryholograms/releases/latest).
2. Покладіть його в папку **`mods/`** гри. Видаліть попередній JAR Factory Holograms, якщо він є.
3. Запустіть гру.

## Як користуватися

1. Наведіться на блок поблизу й натисніть **Shift+H**.
2. Введіть назву та перетягніть іконки предметів з інвентарю або **NEI** у слоти входу й виходу.
3. За потреби змініть положення й натисніть **«Готово» / Apply**.

Справжні предмети залишаються на місці. Мітка вміщує до **16 іконок входу та 16 іконок виходу**. ПКМ по слоту прибирає іконку.

- **Shift+H** на початковому блоці — редагувати його мітку.
- **H** — показати або сховати всі мітки.
- **«Стерти» / Delete** в редакторі — видалити мітку, не блок.
- **Escape** — скасувати незбережені зміни; спершу прибирає копію предмета з курсора, якщо вона є.

## Налаштування

Кольори, непрозорість, дальність і автоповорот: **Mods → Factory Holograms → Config**. Для ручного повороту вимкніть автоповорот і відкрийте **«Поворот / нахил»** у редакторі.

Перепризначити H: **Options → Controls → Factory Holograms**.
