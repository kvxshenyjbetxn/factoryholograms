# Factory Holograms

[English](README.md)

Голографічні назви та іконки входів і виходів над машинами та іншими блоками в **Minecraft 1.7.10**.

Мітки бачите тільки ви, на сервер нічого ставити не треба. Назви й іконки ви обираєте самі. Перевірено на **GTNH 2.9.0 RC-2**; працює без GregTech і NEI.

https://github.com/user-attachments/assets/96eca09f-0427-4458-8abf-a039270e8394

## Встановлення

1. Завантажте **`factoryholograms-0.7.9.jar`** з [останнього релізу](https://github.com/kvxshenyjbetxn/factoryholograms/releases/latest).
2. Покладіть його в папку **`mods/`** гри, замінивши старий JAR Factory Holograms, якщо він є.

## Швидкий старт

Наведіться на блок, натисніть **Shift+H**, введіть назву, перетягніть іконки у слоти входу й виходу та натисніть **«Готово» / Apply**. Справжні предмети лишаються в інвентарі.

Мітка вміщує до **8 рецептів**, у кожному до **16 входів і 16 виходів**. Якщо вихід однієї мітки збігається з входом іншої, їх автоматично з'єднує лінія.

## Керування

**У світі**

| Клавіша | Дія |
|---|---|
| **Shift+H** на блоці | Створити або редагувати його мітку |
| **H** | Показати / сховати всі мітки |
| **Ctrl+H** | Лінії зв'язків: мітка під прицілом / усі / вимкнено |
| **L** | Увімкнути / вимкнути лінії зв'язків |
| Навести на іконку | Підказка предмета (затисніть **Shift** для повної) |
| **R** / **U** при наведенні на іконку | Рецепти / використання в NEI |

**У редакторі**

| Дія | Як |
|---|---|
| Поставити іконку | Перетягнути або клікнути предмет з інвентарю чи NEI |
| Заповнити назву | Кинути іконку на поле назви |
| Очистити слот | ПКМ по слоту |
| Перемкнути / додати / прибрати рецепт | Стрілки та **+** / **-** над слотами |
| Видалити мітку | Кнопка **«Стерти» / Delete** |
| Скасувати зміни | **Escape** |

**H** і **L** можна перепризначити в **Options → Controls → Factory Holograms**.

## Налаштування

Кольори, непрозорість, дальність, автоповорот, підказки й лінії зв'язків: **Mods → Factory Holograms → Config**. Для ручного повороту вимкніть автоповорот і відкрийте **«Поворот / нахил»** у редакторі.
